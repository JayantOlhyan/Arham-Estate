# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Arham Estate seriously. If you discover a security vulnerability, please do NOT create a public issue on GitHub.

Instead, please send an email to `security@arhamestate.com` or `jayantolhyan@gmail.com` with:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested remediations

You can expect an acknowledgment within 48 hours and regular updates on our progress toward resolving the vulnerability.
